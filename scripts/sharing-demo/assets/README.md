# Store badges

Official English artwork downloaded on 2026-09-14:

- `app-store.svg`: https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg
- `google-play.png`: https://play.google.com/intl/en_us/badges/images/generic/en_badge_web_generic.png

The renderer preserves each badge's proportions and displays both at the same
height. The PNG's transparent outer padding is removed for positioning; the
layout supplies the surrounding clear space. The App Store badge appears first.

Usage references:
- https://developer.apple.com/app-store/marketing/guidelines/
- https://partnermarketinghub.withgoogle.com/brands/google-play/google-play/lockups-icons-badges/
